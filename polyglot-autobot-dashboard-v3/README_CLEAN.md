# Polyglot Autobot Dashboard (clean)

This package removes build artifacts and secrets. Reinstall dependencies then start:

```bat
start-all.bat
```

or separately:

```bat
start-api.bat
run-dev.bat
```

Default ports:
- API: http://127.0.0.1:9900
- UI:  http://127.0.0.1:5173

> Note: `node_modules`, `build` and `.vite` were removed. Run `npm install` before starting.
